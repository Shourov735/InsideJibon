# InsideJibon Design System

## Product

InsideJibon is a modern educational learning platform.

## Visual direction

Professional
Academic
Friendly
Calm
Modern

Avoid:
- excessive gradients
- childish illustrations
- excessive glassmorphism
- excessive shadows
- excessive cards

## Typography

Use a clean sans-serif font.

Establish hierarchy for:

- page title
- section heading
- card title
- body
- caption
- labels

## Layout

Use generous whitespace.

Dashboards should prioritize:
1. primary task
2. learning progress
3. upcoming work
4. secondary information

## Components

Use consistent:

- buttons
- cards
- badges
- tabs
- inputs
- dialogs
- tables
- progress indicators

## Responsive

Desktop:
sidebar + content

Mobile:
compact navigation + single-column content

## Principles

Do not create a new visual pattern when an existing component can be reused.
